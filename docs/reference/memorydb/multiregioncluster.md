# aws.multiregioncluster

**CloudFormation type:** `AWS::MemoryDB::MultiRegionCluster`

The AWS::MemoryDB::Multi Region Cluster resource creates an Amazon MemoryDB Multi Region Cluster.

Region attribute: `region`

**Import ID:** `<region>/MultiRegionClusterName` (AWS::MemoryDB::MultiRegionCluster)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `ARN` |  | `string` | computed |  | The Amazon Resource Name (ARN) of the multi region cluster. |
| `Description` |  | `string` | optional, computed, provider-chosen |  | Description of the multi region cluster. |
| `Engine` |  | `string` | optional, computed, provider-chosen |  | The engine type used by the multi region cluster. |
| `EngineVersion` | engine_version | `string` | optional, computed, provider-chosen, replaces on change |  | The Redis engine version used by the multi region cluster. |
| `MultiRegionClusterName` | multi_region_cluster_name | `string` | computed |  | The name of the Global Datastore, it is generated by MemoryDB adding a prefix to MultiRegionClusterNameSuffix. |
| `MultiRegionClusterNameSuffix` | multi_region_cluster_name_suffix | `string` | optional, computed, provider-chosen, replaces on change, write-only |  | The name of the Multi Region cluster. This value must be unique as it also serves as the multi region cluster identifier. |
| `MultiRegionParameterGroupName` | multi_region_parameter_group_name | `string` | optional, computed, provider-chosen, replaces on change |  | The name of the parameter group associated with the multi region cluster. |
| `NodeType` | node_type | `string` | required |  | The compute and memory capacity of the nodes in the multi region cluster. |
| `NumShards` | num_shards | `integer` | optional, computed, provider-chosen |  | The number of shards the multi region cluster will contain. |
| `Status` |  | `string` | computed |  | The status of the multi region cluster. For example, Available, Updating, Creating. |
| `TLSEnabled` | tls_enabled | `boolean` | optional, computed, provider-chosen, replaces on change |  | A flag that enables in-transit encryption when set to true. |
| `Tags` |  | `map` | optional, computed, provider-chosen, tags map |  | An array of key-value pairs to apply to this multi region cluster. |
| `UpdateStrategy` | update_strategy | `string` | optional, computed, provider-chosen, write-only |  | An enum string value that determines the update strategy for scaling. Possible values are 'COORDINATED' and 'UNCOORDINATED'. Default is 'COORDINATED'. |

Supports update: yes

Discovery: supported
