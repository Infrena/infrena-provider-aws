# aws.memorydb.cluster

**CloudFormation type:** `AWS::MemoryDB::Cluster`

The AWS::MemoryDB::Cluster resource creates an Amazon MemoryDB Cluster.

Region attribute: `region`

**Import ID:** `<region>/ClusterName` (AWS::MemoryDB::Cluster)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `ACLName` | acl_name | `string` | required |  | The name of the Access Control List to associate with the cluster. |
| `ARN` |  | `string` | computed |  | The Amazon Resource Name (ARN) of the cluster. |
| `AutoMinorVersionUpgrade` | auto_minor_version_upgrade | `boolean` | optional, computed, provider-chosen |  | A flag that enables automatic minor version upgrade when set to true. |
| `ClusterEndpoint` | cluster_endpoint | `map` | optional, computed, provider-chosen |  | The cluster endpoint. |

| `DataTiering` | data_tiering | `string` | optional, computed, provider-chosen, replaces on change |  | Enables data tiering. Data tiering is only supported for clusters using the r6gd node type. This parameter must be set when using r6gd nodes. |

| `Engine` |  | `string` | optional, computed, provider-chosen |  | The engine type used by the cluster. |
