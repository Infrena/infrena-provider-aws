# aws.moduleversion

**CloudFormation type:** `AWS::CloudFormation::ModuleVersion`

A module that has been registered in the CloudFormation registry.

Region attribute: `region`

**Import ID:** `<region>/Arn` (AWS::CloudFormation::ModuleVersion)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `Arn` |  | `string` | computed |  | The Amazon Resource Name (ARN) of the module. |
| `Description` |  | `string` | computed |  | The description of the registered module. |
| `DocumentationUrl` | documentation_url | `string` | computed |  | The URL of a page providing detailed documentation for this module. |
| `IsDefaultVersion` | is_default_version | `boolean` | computed |  | Indicator of whether this module version is the current default version |
| `ModuleName` | module_name | `string` | required, replaces on change |  | The name of the module being registered. |
| `ModulePackage` | module_package | `string` | required, replaces on change, write-only |  | The url to the S3 bucket containing the schema and template fragment for the module you want to register. |
| `Schema` |  | `string` | computed |  | The schema defining input parameters to and resources generated by the module. |
| `TimeCreated` | time_created | `string` | computed |  | The time that the specified module version was registered. |
| `VersionId` | version_id | `string` | computed |  | The version ID of the module represented by this module instance. |
| `Visibility` |  | `string` | computed |  | The scope at which the type is visible and usable in CloudFormation operations. |

Supports update: no

Discovery: not supported
