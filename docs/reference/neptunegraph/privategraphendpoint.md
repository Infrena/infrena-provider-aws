# aws.privategraphendpoint

**CloudFormation type:** `AWS::NeptuneGraph::PrivateGraphEndpoint`

The AWS::NeptuneGraph::PrivateGraphEndpoint resource creates an Amazon NeptuneGraph PrivateGraphEndpoint.

Region attribute: `region`

**Import ID:** `<region>/PrivateGraphEndpointIdentifier` (AWS::NeptuneGraph::PrivateGraphEndpoint)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `GraphIdentifier` | graph_identifier | `string` | required, replaces on change |  | The auto-generated Graph Id assigned by the service. |
| `PrivateGraphEndpointIdentifier` | private_graph_endpoint_identifier | `string` | computed |  | PrivateGraphEndpoint resource identifier generated by concatenating the associated GraphIdentifier and VpcId with an underscore separator. |
| `SecurityGroupIds` | security_group_ids | `list` | optional, computed, provider-chosen, replaces on change, write-only | aws.securitygroup.Id | The security group Ids associated with the VPC where you want the private graph endpoint to be created, ie, the graph will be reachable from within the VPC. |
| `SubnetIds` | subnet_ids | `list` | optional, computed, provider-chosen, replaces on change | aws.subnet.SubnetId | The subnet Ids associated with the VPC where you want the private graph endpoint to be created, ie, the graph will be reachable from within the VPC. |
| `VpcEndpointId` | vpc_endpoint_id | `string` | computed |  | VPC endpoint that provides a private connection between the Graph and specified VPC. |
| `VpcId` | vpc_id | `string` | required, replaces on change | aws.vpc.VpcId | The VPC where you want the private graph endpoint to be created, ie, the graph will be reachable from within the VPC. |

Supports update: yes

Discovery: supported
