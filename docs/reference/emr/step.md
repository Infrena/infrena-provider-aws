# aws.step

**CloudFormation type:** `AWS::EMR::Step`

Schema for AWS::EMR::Step

Region attribute: `region`

**Import ID:** `<region>/Id` (AWS::EMR::Step)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `ActionOnFailure` | action_on_failure | `string` | required, replaces on change |  | This specifies what action to take when the cluster step fails. Possible values are CANCEL_AND_WAIT and CONTINUE. |
| `EncryptionKeyArn` | encryption_key_arn | `string` | optional, computed, provider-chosen, replaces on change |  | The KMS key ARN to encrypt the logs published to the given Amazon S3 destination. When omitted, EMR falls back to cluster-level logging behavior. |
| `HadoopJarStep` | hadoop_jar_step | `map` | required, replaces on change |  | The HadoopJarStepConfig property type specifies a job flow step consisting of a JAR file whose main function will be executed. The main function submits a job for the cluster to execute as a step on the master node, and then waits for the job to finish or fail before executing subsequent steps. |
| `Id` |  | `string` | computed |  | ID generated by service |
| `JobFlowId` | job_flow_id | `string` | required, replaces on change |  | A string that uniquely identifies the cluster (job flow). |
| `LogUri` | log_uri | `string` | optional, computed, provider-chosen, replaces on change |  | The Amazon S3 destination URI for log publishing. When omitted, EMR falls back to cluster-level logging behavior. |
| `Name` |  | `string` | required, replaces on change |  | The name of the cluster step. |

Supports update: no
