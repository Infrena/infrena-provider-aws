# aws.dms.eventsubscription

**CloudFormation type:** `AWS::DMS::EventSubscription`

Resource Type definition for AWS::DMS::EventSubscription

Region attribute: `region`

**Import ID:** `<region>/SubscriptionName` (AWS::DMS::EventSubscription)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `Enabled` |  | `boolean` | optional, computed, provider-chosen |  | Indicates whether to activate the subscription. If you don't specify this property, CloudFormation activates the subscription. |
| `EventCategories` | event_categories | `list` | optional, computed, provider-chosen |  | A list of event categories for a source type that you want to subscribe to. If you don't specify this property, you are notified about all event categories. |
| `SnsTopicArn` | sns_topic_arn | `string` | required |  | The Amazon Resource Name (ARN) of the Amazon SNS topic created for event notification. The ARN is created by Amazon SNS when you create a topic and subscribe to it. |
| `SourceIds` | source_ids | `list` | optional, computed, provider-chosen, replaces on change |  | A list of identifiers for which AWS DMS provides notification events. |
| `SourceType` | source_type | `string` | optional, computed, provider-chosen |  | The type of AWS DMS resource that generates the events. For example, if you want to be notified of events generated by a replication instance, you set this parameter to replication-instance. If this value isn't specified, all events are returned. |
| `SubscriptionName` | subscription_name | `string` | optional, computed, provider-chosen, replaces on change |  | The name of the AWS DMS event notification subscription. This name must be less than 255 characters. |
| `Tags` |  | `map` | tags map |  | One or more tags to be assigned to the event subscription. |

Supports update: yes

Discovery: supported
