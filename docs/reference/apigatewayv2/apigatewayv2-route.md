# aws.apigatewayv2.route

**CloudFormation type:** `AWS::ApiGatewayV2::Route`

The ``AWS::ApiGatewayV2::Route`` resource creates a route for an API.

Region attribute: `region`

**Import ID:** `<region>/ApiId|RouteId` (AWS::ApiGatewayV2::Route)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `ApiId` | api_id | `string` | required, replaces on change | aws.apigatewayv2.api.ApiId | The API identifier. |
| `ApiKeyRequired` | api_key_required | `boolean` | optional, computed, provider-chosen |  | Specifies whether an API key is required for the route. Supported only for WebSocket APIs. |
| `AuthorizationScopes` | authorization_scopes | `list` | optional, computed, provider-chosen |  | The authorization scopes supported by this route. |
| `AuthorizationType` | authorization_type | `string` | optional, computed, provider-chosen |  | The authorization type for the route. For WebSocket APIs, valid values are ``NONE`` for open access, ``AWS_IAM`` for using AWS IAM permissions, and ``CUSTOM`` for using a Lambda authorizer. For HTTP APIs, valid values are ``NONE`` for open access, ``JWT`` for using JSON Web Tokens, ``AWS_IAM`` for using AWS IAM permissions, and ``CUSTOM`` for using a Lambda authorizer. |
| `AuthorizerId` | authorizer_id | `string` | optional, computed, provider-chosen, write-only | aws.apigatewayv2.authorizer.AuthorizerId | The identifier of the ``Authorizer`` resource to be associated with this route. The authorizer identifier is generated by API Gateway when you created the authorizer. |
| `ModelSelectionExpression` | model_selection_expression | `string` | optional, computed, provider-chosen |  | The model selection expression for the route. Supported only for WebSocket APIs. |
| `OperationName` | operation_name | `string` | optional, computed, provider-chosen |  | The operation name for the route. |
| `RequestModels` | request_models | `map` | optional, computed, provider-chosen |  | The request models for the route. Supported only for WebSocket APIs. |
| `RequestParameters` | request_parameters | `map` | optional, computed, provider-chosen, write-only |  | The request parameters for the route. Supported only for WebSocket APIs. |
| `RouteId` | route_id | `string` | computed |  |  |
| `RouteKey` | route_key | `string` | required |  | The route key for the route. For HTTP APIs, the route key can be either ``$default``, or a combination of an HTTP method and resource path, for example, ``GET /pets``. |
| `RouteResponseSelectionExpression` | route_response_selection_expression | `string` | optional, computed, provider-chosen |  | The route response selection expression for the route. Supported only for WebSocket APIs. |
| `Target` |  | `string` | optional, computed, provider-chosen |  | The target for the route. |

Supports update: yes

Discovery: supported (parent resource required)
