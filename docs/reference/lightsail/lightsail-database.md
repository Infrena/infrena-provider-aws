# aws.lightsail.database

**CloudFormation type:** `AWS::Lightsail::Database`

Resource Type definition for AWS::Lightsail::Database

Region attribute: `region`

**Import ID:** `<region>/RelationalDatabaseName` (AWS::Lightsail::Database)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `AvailabilityZone` | availability_zone | `string` | optional, computed, provider-chosen, replaces on change |  | The Availability Zone in which to create your new database. Use the us-east-2a case-sensitive format. |
| `BackupRetention` | backup_retention | `boolean` | optional, computed, provider-chosen |  | When true, enables automated backup retention for your database. Updates are applied during the next maintenance window because this can result in an outage. |
| `CaCertificateIdentifier` | ca_certificate_identifier | `string` | optional, computed, provider-chosen |  | Indicates the certificate that needs to be associated with the database. |
| `DatabaseArn` | database_arn | `string` | computed |  |  |
| `MasterDatabaseName` | master_database_name | `string` | required, replaces on change |  | The name of the database to create when the Lightsail database resource is created. For MySQL, if this parameter isn't specified, no database is created in the database resource. For PostgreSQL, if this parameter isn't specified, a database named postgres is created in the database resource. |
| `MasterUserPassword` | master_user_password | `string` | optional, computed, provider-chosen, sensitive, write-only |  | The password for the master user. The password can include any printable ASCII character except "/", """, or "@". It cannot contain spaces. |
| `MasterUsername` | master_username | `string` | required, replaces on change |  | The name for the master user. |
| `PreferredBackupWindow` | preferred_backup_window | `string` | optional, computed, provider-chosen |  | The daily time range during which automated backups are created for your new database if automated backups are enabled. |
| `PreferredMaintenanceWindow` | preferred_maintenance_window | `string` | optional, computed, provider-chosen |  | The weekly time range during which system maintenance can occur on your new database. |
| `PubliclyAccessible` | publicly_accessible | `boolean` | optional, computed, provider-chosen |  | Specifies the accessibility options for your new database. A value of true specifies a database that is available to resources outside of your Lightsail account. A value of false specifies a database that is available only to your Lightsail resources in the same region as your database. |
| `RelationalDatabaseBlueprintId` | relational_database_blueprint_id | `string` | required, replaces on change |  | The blueprint ID for your new database. A blueprint describes the major engine version of a database. |
| `RelationalDatabaseBundleId` | relational_database_bundle_id | `string` | required, replaces on change |  | The bundle ID for your new database. A bundle describes the performance specifications for your database. |
| `RelationalDatabaseName` | relational_database_name | `string` | required, replaces on change |  | The name to use for your new Lightsail database resource. |
| `RelationalDatabaseParameters` | relational_database_parameters | `list` | optional, computed, provider-chosen, write-only |  | Update one or more parameters of the relational database. |
| `RotateMasterUserPassword` | rotate_master_user_password | `boolean` | optional, computed, provider-chosen, write-only |  | When true, the master user password is changed to a new strong password generated by Lightsail. Use the get relational database master user password operation to get the new password. |
| `Tags` |  | `map` | tags map |  | An array of key-value pairs to apply to this resource. |

Supports update: yes

Discovery: supported
