# aws.appsync.api

**CloudFormation type:** `AWS::AppSync::Api`

Resource schema for AppSync Api

Region attribute: `region`

**Import ID:** `<region>/ApiArn` (AWS::AppSync::Api)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `ApiArn` | api_arn | `string` | computed |  | The Amazon Resource Name (ARN) of the AppSync Api |
| `ApiId` | api_id | `string` | computed |  | The unique identifier for the AppSync Api generated by the service |
| `Dns` |  | `map` | computed |  | A map of DNS names for the AppSync API. |
| `EventConfig` | event_config | `map` | optional, computed, provider-chosen |  | The configuration for an Event Api |
| `Name` |  | `string` | required |  | The name of the AppSync API. |
| `OwnerContact` | owner_contact | `string` | optional, computed, provider-chosen |  | The owner contact information for an API resource. |
| `Tags` |  | `map` | tags map |  | An arbitrary set of tags (key-value pairs) for this AppSync API. |

Supports update: yes

Discovery: supported
