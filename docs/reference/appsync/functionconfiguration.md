# aws.functionconfiguration

**CloudFormation type:** `AWS::AppSync::FunctionConfiguration`

An example resource schema demonstrating some basic constructs and validation rules.

Region attribute: `region`

**Import ID:** `<region>/FunctionArn` (AWS::AppSync::FunctionConfiguration)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `ApiId` | api_id | `string` | required, replaces on change | aws.appsync.api.ApiId | The AWS AppSync GraphQL API that you want to attach using this function. |
| `Code` |  | `string` | optional, computed, provider-chosen |  | The resolver code that contains the request and response functions. When code is used, the runtime is required. The runtime value must be APPSYNC_JS. |
| `CodeS3Location` | code_s3_location | `string` | optional, computed, provider-chosen, write-only |  | The Amazon S3 endpoint (where the code is located??). |
| `DataSourceName` | data_source_name | `string` | required |  | The name of data source this function will attach. |
| `Description` |  | `string` | optional, computed, provider-chosen |  | The function description. |
| `FunctionArn` | function_arn | `string` | computed |  | The ARN for the function generated by the service |
| `FunctionId` | function_id | `string` | computed |  | The unique identifier for the function generated by the service |
| `FunctionVersion` | function_version | `string` | optional, computed, provider-chosen |  | The version of the request mapping template. Currently, only the 2018-05-29 version of the template is supported. |
| `MaxBatchSize` | max_batch_size | `integer` | optional, computed, provider-chosen |  | The maximum number of resolver request inputs that will be sent to a single AWS Lambda function in a BatchInvoke operation. |
| `Name` |  | `string` | required |  | The name of the function. |
| `RequestMappingTemplate` | request_mapping_template | `string` | optional, computed, provider-chosen |  | The Function request mapping template. Functions support only the 2018-05-29 version of the request mapping template. |
| `RequestMappingTemplateS3Location` | request_mapping_template_s3_location | `string` | optional, computed, provider-chosen, write-only |  | Describes a Sync configuration for a resolver. Contains information on which Conflict Detection, as well as Resolution strategy, should be performed when the resolver is invoked. |
| `ResponseMappingTemplate` | response_mapping_template | `string` | optional, computed, provider-chosen |  | The Function response mapping template. |
| `ResponseMappingTemplateS3Location` | response_mapping_template_s3_location | `string` | optional, computed, provider-chosen, write-only |  | The location of a response mapping template in an Amazon S3 bucket. Use this if you want to provision with a template file in Amazon S3 rather than embedding it in your CloudFormation template. |
| `Runtime` |  | `map` | optional, computed, provider-chosen |  | Describes a runtime used by an AWS AppSync pipeline resolver or AWS AppSync function. Specifies the name and version of the runtime to use. Note that if a runtime is specified, code must also be specified. |
| `SyncConfig` | sync_config | `map` | optional, computed, provider-chosen |  | Describes a Sync configuration for a resolver. Specifies which Conflict Detection strategy and Resolution strategy to use when the resolver is invoked. |

Supports update: yes

Discovery: supported (parent resource required)
