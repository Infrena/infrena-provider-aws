# aws.codepipeline.webhook

**CloudFormation type:** `AWS::CodePipeline::Webhook`

Resource Type definition for AWS::CodePipeline::Webhook

Region attribute: `region`

**Import ID:** `<region>/Id` (AWS::CodePipeline::Webhook)

## Attributes

| Attribute | Also written as | Kind | Flags | References | Description |
|-----------|-----------------|------|-------|------------|-------------|
| `Authentication` |  | `string` | required |  | Supported options are GITHUB_HMAC, IP, and UNAUTHENTICATED. |
| `AuthenticationConfiguration` | authentication_configuration | `map` | required |  | Properties that configure the authentication applied to incoming webhook trigger requests |
| `Filters` |  | `list` | required |  | A list of rules applied to the body/payload sent in the POST request to a webhook URL |
| `Id` |  | `string` | computed |  | logical id of the webhook |
| `Name` |  | `string` | optional, computed, provider-chosen, replaces on change |  | The name of the webhook |
| `RegisterWithThirdParty` | register_with_third_party | `boolean` | optional, computed, provider-chosen, write-only |  | Configures a connection between the webhook that was created and the external tool with events to be detected. |
| `Tags` |  | `map` | optional, computed, provider-chosen, tags map |  | An array of key-value pairs to apply to this resource. |
| `TargetAction` | target_action | `string` | required |  | The name of the action in a pipeline you want to connect to the webhook. |
| `TargetPipeline` | target_pipeline | `string` | required |  | The name of the pipeline you want to connect to the webhook. |
| `TargetPipelineVersion` | target_pipeline_version | `integer` | optional, computed, provider-chosen, write-only |  | The version number of the pipeline to be connected to the trigger request. |
| `Url` |  | `string` | computed |  | The webhook URL generated by AWS CodePipeline |

Supports update: yes

Discovery: supported
