# aws.globalreplicationgroup

**CloudFormation type:** `AWS::ElastiCache::GlobalReplicationGroup`

The AWS::ElastiCache::GlobalReplicationGroup resource creates an Amazon ElastiCache Global Replication Group.

Region attribute: `region`

**Import ID:** `<region>/GlobalReplicationGroupId` (AWS::ElastiCache::GlobalReplicationGroup)

## Attributes
